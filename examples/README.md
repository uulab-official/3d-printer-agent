# 실제 생성 샘플

각 폴더에는 모델 형상의 STL·STEP·3MF, 이를 다시 생성하는 `model.py`, 치수·검사·SHA-256을 기록한 `manifest.json`이 있습니다.

| 폴더 | 모델 | 외부 치수 (mm) | 특징 |
|---|---|---|---|
| tray | 수납함 | 120 × 80 × 35 | 2mm 벽·바닥, 칸막이 2개로 3칸 |
| cable_comb | 열린 케이블 받침 | 80 × 18 × 12 | 6mm 케이블 + 지름 여유 0.3mm, 홈 5개 |
| magnet_frame | 원형 인셋 프레임 | 65 × 65 × 7 | 원판 지름 52mm + 여유 0.3mm, 포켓 깊이 2mm |

세 모델 모두 실제 CAD 생성 및 STEP 재읽기 검사를 통과했습니다. 3MF는 형상 파일이며 슬라이싱된 출력 파일이 아닙니다. 실물 출력·자석 유지력·케이블 고정력·끼워맞춤은 검증하지 않았습니다.

CadQuery 의존성을 설치한 환경에서 다음처럼 새 폴더로 재생산할 수 있습니다.

```bash
python examples/tray/model.py ./reproduced-tray
```

같은 위치에 모델 파일이 이미 있으면 덮어쓰지 않습니다. 모델의 단위는 mm입니다.
