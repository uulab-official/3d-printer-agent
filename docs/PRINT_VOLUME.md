# 현재 CAD의 출력 크기 확인

v0.8은 **생성한 CAD 파일의 실제 치수**와 **선택한 설정에 기록된 출력 공간**을
준비 전에 비교합니다. Studio 프로젝트를 선택하는 방법과 수동 전체 설정 JSON을
제공하는 앱 화면 모두에 적용됩니다. 별도 API 키나 Studio 설치 없이 프로젝트
파일의 크기 검토를 사용할 수 있습니다.

## 사용 순서

1. 만들거리나 요청으로 CAD를 생성합니다.
2. 사용할 Studio 프로젝트를 가져오거나 보관함에서 선택합니다.
3. **크기 확인 후 3MF 준비**를 누릅니다.
4. 현재 CAD와 기록된 출력 공간의 가로·세로·높이 표, 0°·90° 비교를 확인합니다.
5. 추가 확인이 필요하면 **현재 치수 수정하기**로 돌아가 치수를 수정하고 CAD를
   다시 만듭니다. 다른 프린터의 설정을 선택할 수도 있습니다.

준비 실패 시 이전 준비 파일을 현재 결과로 표시하지 않습니다. 원본 CAD와 가져온
Studio 원본은 보관합니다. 파일의 크기를 자동 축소하거나 모델에 회전을 적용하지
않습니다. 과거 기록에서 보이는 표는 당시의 비교이며, 다시 준비할 때 현재 파일과
설정으로 재검사합니다.

## 결과의 의미

| 결과 | 의미 | 다음 행동 |
|---|---|---|
| 크기 비교 완료 | 지원하는 기록 영역 안에 CAD 외곽 상자를 0° 또는 90°로 놓을 수 있는 위치를 찾음 | 설정 포함 파일을 내려받고 Studio에서 실제 배치·슬라이싱 확인 |
| 기록된 출력 높이 초과 | 세워 둔 CAD 높이가 설정의 높이 한도를 초과함 | 높이 또는 선택한 프린터 설정 확인 |
| 배치 추가 확인 필요 | 0°·90°에서 위치를 찾지 못했거나, 영역·추가 제한을 이 검사에서 해석할 수 없음 | 치수·설정 변경 또는 원본 CAD를 Studio에서 직접 검토 |

0°·90° 비교가 실패해도 대각선 배치까지 불가능하다는 뜻은 아닙니다. 예를 들어
가늘고 긴 물체는 다른 각도로 놓을 수 있습니다. 이 버전은 일반 각도의 배치나
기울여 놓기를 계산하지 않습니다.

## 지원하는 영역

출력 영역은 축에 평행한 직사각형으로, 네 모서리가 둘레 순서로 기록되어야 합니다.
시계·반시계 방향과 마지막에 시작점을 반복한 형식을 지원합니다. 음수 좌표나
이동된 원점도 처리합니다. 오목한 영역·마름모·교차한 꼭짓점은 외곽 크기만 보고
통과시키지 않습니다.

명시된 베드 제외 영역은 네 점씩 묶인 직사각형을 지원합니다. 제외 영역의 경계와
베드 경계에서 유한한 배치 후보를 검사합니다. `bed_exclude_area`의 빈 배열과
기본 원점 한 점은 명시적인 제외 사각형이 없는 상태로 처리합니다. 해석하지 못하는
압출기별 영역·추가 높이·추가 제외 영역이 있으면 확인 필요 상태로 남깁니다.
원본에서 선택적 제한 필드를 제공하지 않은 경우에는 그 누락을 보고서에 표시합니다.

이는 고정한 Bambu Studio 소스에서 확인한 형식에 따른 제한된 해석입니다.

- [PrintConfig.cpp](https://github.com/bambulab/BambuStudio/blob/56a57d00a591360cf41bf21383915ee5bf357be5/src/libslic3r/PrintConfig.cpp): 출력 영역·높이와 기본 제외 영역·압출기별 높이 정의.
- [Print.cpp](https://github.com/bambulab/BambuStudio/blob/56a57d00a591360cf41bf21383915ee5bf357be5/src/libslic3r/Print.cpp): 네 꼭짓점 단위의 제외 영역 처리.

수치 비교의 절대 허용 오차는 **0.000001mm**입니다. 이 값은 메시 숫자의 계산 오차를
다루며, 실물 출력 여유나 조립 공차가 아닙니다. 경계와 맞닿는 외곽 상자는 이 수치
검사를 통과할 수 있습니다. 브림·스커트·서포트·퍼지 구조물·이동 공간은 별도로
슬라이서에서 확인해야 합니다. 파일의 프린터 이름은 실제 장착 장비의 확인을 대신하지
않습니다.

## 기록과 API

`POST /api/slice`는 기존 요청 형식을 유지합니다. 성공 또는 크기 검토 실패 결과의
`plan.print_volume`에 다음 내용을 포함합니다.

- `status`, `can_prepare`, `scope`, `schema_version`.
- `model_dimensions_mm`, `recorded_volume_mm`: 가로·세로·높이, 미확인 값은 `null`.
- `orientations`: 0°·90° 각각의 비교 결과.
- `placement_mm`, `rotation_degrees`, `placement_applied: false`: 발견한 외곽 상자의
  최소 XY 좌표와 방향. 파일이나 실제 native 배치에 적용한 변환이 아닙니다.
- `issues`, `limitations`, `tolerance_mm`.
- `model_sha256`, `settings_sha256`: 검사에 사용한 CAD와 설정의 식별 정보.

Studio 경로의 설정 해시는 원본 또는 검증한 편집본의 정확한 설정 바이트 해시입니다.
수동 경로는 검증한 machine JSON을 정렬된 키·공백 없는 UTF-8 JSON으로 직렬화한
해시입니다. process나 filament 파일이 출력 영역 필드를 중복 제공하면 우선순위를
추정하지 않고 준비를 중단합니다.

성공한 Studio 준비 기록에도 동일한 보고서를 보관합니다. native 실행 직전에 보관한
원본 CAD와 설정으로 다시 계산하여 보고서가 바뀌거나 누락된 계획을 거절합니다.
앱 외부에서 직접 사용하는 기존 STL용 Python 어댑터는 이 생성 CAD 검사를 수행했다고
표시하지 않습니다. 앱의 수동 JSON 경로는 검사를 생략할 수 없습니다.

## 검증 범위

기하 판정과 실제 CAD·API·준비 기록 테스트는 물리 프린터 없이 실행할 수 있습니다.
설치 패키지 검증은 초과 모델이 준비되지 않는 동작과 재시작·백업 복원 후의 보고서
보존을 확인합니다. 실제 데스크톱·모바일 Chromium 경로와 native 회귀 결과는
[검증 기록](VERIFICATION.md)에 실행한 커밋별로 남깁니다.
