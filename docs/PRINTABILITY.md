# 미리보기와 출력 전 형상 점검

v0.10은 생성한 CAD를 **여러 시점과 치수선**으로 확인하고, 슬라이싱 전에 **출력하기 어려운 부분**을
알려 주는 점검 카드를 추가합니다. 점검은 조언이며 생성을 막지 않습니다.

## 미리보기

- **입체·정면·측면·윗면** 버튼으로 시점을 바꿉니다. 드래그하면 직접 조정한 시점이 됩니다.
- **치수**: 외곽 가로·세로·높이를 주황색 치수선으로 표시합니다. 화면을 향해 거의 수직인 축은 길이를
  읽을 수 없으므로 숨깁니다.
- **돌출부**: 바닥이 아닌데 아래를 45° 넘게 향하는 면을 주황색으로 칠합니다.
- **이전 모델 겹쳐 보기**: 치수를 바꿔 다시 생성하면 직전 모델을 회색 점선 윤곽으로 함께 그립니다. 칩에
  `이전 120 × 80 × 35 mm`처럼 표시되며 끌 수 있습니다. 같은 크기로 다시 만들면 표시하지 않습니다. 점선은
  음영이 없어 현재 CAD와 구분됩니다.
- 꺾이는 모서리만 선으로 그리고, 가려진 모서리는 깊이 검사로 숨깁니다. 조명은 시점을 따라가므로 어느
  방향에서도 면이 구분됩니다.

## 점검 항목

생성할 때는 **0.4 mm 노즐, 0.42 mm 압출 폭**으로 점검해 작업에 저장합니다. 카드의 **점검할 노즐**에서
0.2·0.4·0.6·0.8 mm를 고르면 저장된 형상으로 다시 계산합니다(압출 폭 = 노즐 × 1.05). 다시 계산해도 저장된
작업과 파일은 바뀌지 않습니다. 같은 화면에서 프린터 상태를 읽어 프린터가 노즐 지름을 보고했다면
**프린터가 보고한 0.6 mm 노즐로 점검** 버튼이 나타납니다. 자동으로 바꾸지 않고 사용자가 누를 때만 적용합니다.

| 항목 | 계산 | 상태 |
|---|---|---|
| 가장 얇은 부분 | 템플릿 치수에서 바깥 벽·바닥·칸막이·홈 사이 벽·포켓 둘레/아래 두께를 계산 | 압출 폭 미만 실패, 2줄 미만 주의 |
| 바닥 접촉면 | 메시에서 가장 낮은 높이의 아래 방향 평면 면적 ÷ 외곽 바닥 면적 | 50% 이상 통과, 15% 미만 실패 |
| 세운 비율 | 높이 ÷ 짧은 바닥 변 | 3 초과 주의 |
| 45° 넘는 돌출부 | 바닥이 아닌 아래 방향(법선 z < −0.707) 면적 | 1 mm² 초과 주의 |
| 끼움 여유 | 케이블 받침·원형 프레임만 | 0.2 mm 미만 주의 |
| 재료 사용 상한 | CAD 체적 × PLA 1.24 g/cm³ | 항상 참고값 (속 100% 기준 상한) |

주의·실패 항목에는 바꿀 치수가 있으면 **이 치수 고치기** 버튼이 나타나 해당 입력으로 이동합니다.
값을 바꾸면 이전 결과는 숨겨지고, 다시 생성하면 새 형상으로 점검합니다.

## 한계

- 슬라이서 결과(실제 압출 경로·지지대·사용량)가 아닙니다. 실제 장비와 설정에서 다시 확인하세요.
- 브리지·얇은 기둥·내부 공동 같은 일반 형상의 위험은 현재 네 템플릿에 해당하지 않아 계산하지 않습니다.
  새 템플릿을 추가할 때 같은 경로에 항목을 추가합니다.
- 이전 버전에서 만든 작업 기록에는 저장된 점검 결과가 없습니다. 기록을 열면 **이 작업 점검하기**로 저장된
  형상을 점검할 수 있습니다.
