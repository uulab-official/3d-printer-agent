# 모델 색

## 무엇을 정하나요

- **모델 색**(`color`): 모든 템플릿에서 고를 수 있습니다.
- **글자 색**(`accent_color`): 이름 키링에서만 고를 수 있습니다. 받침과 다른 색이면 두 부품으로 나눕니다.

색은 흰색·검정·회색·빨강·주황·노랑·초록·파랑·보라·분홍·갈색 11가지 이름 중 하나입니다.
화면 색은 비슷하게 보여 줄 뿐이며, 실제 출력 색은 프린터에 넣은 필라멘트가 정합니다.
색을 고르지 않은 모델은 예전과 같은 파라미터·파일·기록 해시를 그대로 유지합니다.

## 정하는 방법

- **요청 문장:** “빨간 글자로 "지우" 키링, 판은 흰색”, “파란색 수납함 가로 12cm”, “노란 키링 이름 민수”
- **수정 문장:** “글자를 빨간색으로 바꿔줘”, “판은 흰색, 글자는 검정으로 해줘”, “색을 초록으로”,
  “글자를 "Mia"로 바꾸고 글자 크기 15mm”, “파란색으로 하고 높이를 5mm 늘려줘”
- **치수 패널:** “색” 묶음의 견본을 누릅니다. 설정 복사·붙여넣기에도 색이 함께 들어갑니다.

“글자”가 붙은 색은 글자 색, 그 밖의 색은 모델 색으로 읽습니다. 같은 부분에 서로 다른 색을 쓰면 하나를 묻고,
키링이 아닌 모델의 글자 색은 거절합니다. 영어 색 이름(red 등)은 단어 전체가 일치할 때만 읽습니다.

## 두 색 키링 파일

글자 색이 받침 색과 다르면 기존 STL·STEP·3MF에 더해 **색상 3MF**(`model-colors.3mf`)를 만듭니다.

- 받침판 윗면 높이에서 형상을 나눠 **받침(필라멘트 1)**과 **글자(필라멘트 2)** 두 부품을 한 물체로 묶습니다.
  두 부품의 체적 합이 원래 모델과 같은지 확인합니다.
- Bambu Studio 형식의 부품별 필라멘트 번호만 담습니다. 프린터·공정·필라멘트 설정은 사용자의 Studio 설정을 씁니다.
- Studio에서 열어 필라멘트 1·2 슬롯에 원하는 색을 지정해 출력합니다. 한 번에 두 색을 뽑으려면 AMS 같은 자동
  필라멘트 교체 장치가 필요합니다.
- 미리보기는 같은 높이 기준으로 면을 색칠하고, 아래에 부품·필라멘트 번호·꽉 찬 기준 PLA 무게를 표시합니다.

**실제 Studio 확인(2026-11-17, macOS, Studio 02.09.01.70):** 앱이 만든 “JIWOO” 색상 3MF를 합성 설정과 흰색·빨강
필라멘트 두 개로 CLI 슬라이싱했습니다. 레이어 1~10은 필라멘트 1(2.03 g), 11~20은 필라멘트 2(0.66 g)를 썼고
필라멘트 교체가 한 번 들어갔습니다. 실물 출력과 AMS 동작은 확인하지 않았습니다.

## 남은 범위

- 앱 안의 Studio 프로젝트 슬라이싱은 아직 필라멘트 하나만 지원합니다. 두 색은 색상 3MF를 Studio에서 열어 출력하세요.
  여러 필라멘트 지원을 시험한 결과(2026-11-17, Studio 02.09.01.70) 두 가지를 확인해 보류했습니다.
  - 공식 예제 전체 프리셋 두 개로 만든 프로젝트는 `nozzle_temperature` 등 필라멘트별 배열이 필라멘트×압출 변형(2×2=4)으로
    펼쳐져 있어, “필라멘트 수와 같은 길이” 규칙으로는 올바르게 검사할 수 없습니다.
  - 일부 필라멘트별 배열이 1개뿐인 프로젝트로 두 부품 모델을 슬라이싱하면 Studio가 성공을 보고하면서 글자 부품을
    빼고 출력했습니다(글자 레이어에 필라멘트 없음).
  실제 프린터에서 필라멘트 2개 이상으로 저장한 Studio 프로젝트로 배열 구조를 검증하고, 슬라이스 뒤 모든 부품의 필라멘트가
  실제로 쓰였는지 확인하는 검사를 함께 넣어야 안전하게 지원할 수 있습니다.
- 키링 외 템플릿은 한 가지 색만 정할 수 있습니다.
