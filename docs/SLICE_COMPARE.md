# 품질별 슬라이스 비교

같은 모델을 **공정 설정 몇 개만 바꿔 네 번 슬라이스**하고, 예상 시간·재료·레이어 수·서포트 여부를 나란히 보여 줍니다.
모델 만들기 화면의 **고급 · 전체 설정 JSON으로 직접 준비하기**에서 설정 JSON을 넣은 뒤 **품질별 4가지 비교**를 누릅니다.
앱이 만든 모델과 불러온 모델 모두에 쓸 수 있습니다.

## 네 가지 설정

프린터(machine)·필라멘트 설정, 플레이트와 모델은 그대로 둡니다. 아래 표의 공정(process) 값만 바꿉니다.

| 설정 | 바꾸는 값 |
|---|---|
| 지금 설정 | 바꾸지 않음 |
| 곱게 | 레이어 높이 = 노즐 지름 × 0.3 (0.4 mm 노즐이면 0.12 mm, 최소 0.06 mm) |
| 빠르게 | 레이어 높이 = 노즐 지름 × 0.7 (0.4 mm 노즐이면 0.28 mm), 채움 10% |
| 튼튼하게 | 벽 +2줄, 윗면·바닥 껍질 +1층, 채움 40% |

- 노즐 지름은 machine 설정의 `nozzle_diameter`에서 읽습니다.
- 벽·껍질 수를 읽을 수 없으면 비교를 시작하지 않고 이유를 알려 줍니다.

## 동작

- **슬라이스:** 설정마다 평소와 같은 준비 단계를 거칩니다. 출력 크기 검토, 설정 묶음 검증, 실행 계획 확인입니다. 그다음 Bambu Studio로 슬라이스합니다.
- **결과 표시:** 슬라이스 파일에서 예상 시간, 재료(g), 레이어 수, 서포트가 있는지를 읽습니다. 표에는 지금 설정 대비 몇 %인지도 함께 보여 줍니다.
- **기존 결과 보존:** 임시 슬라이스 파일은 끝나면 지웁니다. **현재 슬라이스 결과와 내려받을 파일은 바꾸지 않습니다.** 비교 결과(예상치)는 작업에 남아서 다시 열어도 보입니다.
- **설정 적용:** **이 설정 적용**을 누르면 설정 JSON에서 해당 키만 바꿉니다. 바로 슬라이스하지 않으므로, 실행 계획을 다시 검토한 뒤 평소처럼 슬라이싱하세요.
- **지원 범위:** Studio 프로젝트(.3mf) 방식의 설정은 아직 비교하지 않습니다. 전체 설정 JSON 방식만 지원합니다.

## 확인한 것과 하지 않은 것

- **로컬 확인:** Bambu Studio 02.09.01.70(macOS, 합성 설정)으로 확인했습니다.

  | 모델 | 지금 설정 | 곱게 | 빠르게 | 튼튼하게 |
  |---|---|---|---|---|
  | 연필꽂이 70 × 100 mm | 247분 · 52 g · 500층 | 392분 · 833층 | 176분 · 357층 | 60 g |
  | 원래 예제(케이블 받침) | 60층 · 6.85 g | 99층 | 43층 | 10.97 g |

- **Native CI:** Linux Studio 02.09.01.70에서 원래 예제를 네 설정으로 실제 슬라이스합니다. 다음을 매번 확인합니다.
  - 네 설정 모두 슬라이스되는지
  - 레이어 수가 곱게 > 지금 > 빠르게 순서인지
  - 튼튼하게가 재료를 더 쓰는지
- **확인하지 않은 것:** 표의 값은 슬라이서의 **예상치**입니다. 실제 출력 시간·강도·표면 품질은 측정하지 않았습니다.
