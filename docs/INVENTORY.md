# 필라멘트 재고

가진 스풀과 남은 양을 기록합니다. 왼쪽 메뉴의 **필라멘트 재고**에서 씁니다.

## 기록하는 것

- **스풀 정보:** 브랜드, 재료(예: PLA, PETG-CF), 색 이름과 색, 지름(1.75 mm)을 적습니다. 색 이름을 “흰색”, “빨간색”, “Blue”처럼 흔한 이름으로 적으면 색 선택이 그 색으로 채워집니다. 색을 직접 고르면 그 뒤로는 바꾸지 않습니다.
- **무게:** 새 스풀의 필라멘트 무게, 빈 스풀 무게, 남은 양을 적습니다.
- **그 밖의 정보:** 상태(미개봉·개봉·프린터에 장착·건조 중·다 씀), 보관 위치, 가격(선택), 메모를 적습니다.
- **이력:** 변경할 때마다 이력이 남습니다(최근 200개). 남은 양이 0이 되면 **다 씀**이 되고, 미개봉 스풀이 줄면 **개봉**이 됩니다. 직접 수정할 때도 같은 규칙을 씁니다: 남은 양을 0으로 적으면 **다 씀**, 미개봉 스풀의 남은 양을 새 스풀 무게보다 적게 적으면 **개봉**이 됩니다. 직접 고른 **프린터에 장착**·**건조 중**·**다 씀**은 그대로 둡니다.

## 남은 양 바꾸기

- **무게 반영:** 저울에 스풀째 올린 무게를 적으면 빈 스풀 무게를 뺀 값이 남은 양이 됩니다(0 ~ 새 스풀 무게 사이).
- **출력에 쓴 양 빼기:** 슬라이스한 작업의 결과 카드에 **재고에서 빼기**가 나옵니다.
  - 슬라이서 예상 사용량을 기본으로 채워 주며, 직접 고칠 수 있습니다.
  - 같은 출력은 같은 스풀에서 한 번만 뺄 수 있고, 어느 작업에서 뺐는지 이력에 남습니다.
  - 뺀 뒤 기록상 남은 양을 알려 주고, 150 g 미만이면 다음 출력 전에 저울로 확인하라고 경고합니다.
  - 어느 작업에서 뺐는지는 화면 이력(최근 200개)과 따로 최근 1,000건까지 저장합니다. 오래된 이력이 밀려나도 같은 출력을 다시 뺄 수 없고, 결과 카드에도 이미 뺐다고 표시됩니다.
- **수정:** 값을 직접 고칠 수 있습니다. 다른 탭에서 먼저 바뀌었으면 덮어쓰지 않고 최신 값을 알려 줍니다(409 `inventory_conflict`).

## 한눈에 보기와 내보내기

- **한눈에 보기:** 사용 중인 스풀 수, 남은 양 합계, 재료별 합계를 보여 줍니다. 가격을 적었다면 남은 재료의 가치도 보여 줍니다.
  150 g 미만인 스풀은 다른 색으로 표시합니다.
- **CSV 내려받기:** 엑셀에서 바로 열립니다(UTF-8 BOM). `=`·`+`·`-`·`@`로 시작하는 칸은 수식으로 실행되지 않게 앞에 `'`를 붙입니다.
- **손상된 기록:** 읽을 수 없는 기록은 원본을 그대로 두고 목록에서 빼며, 몇 개인지 알려 줍니다. JSON으로 열리더라도 필요한 값이 빠졌거나 형식이 틀린 기록(예: 상태 없음, 남은 양이 문자열)도 같은 방식으로 보존하고 건너뜁니다.

## 저장과 확인

- **저장 위치:** 스풀마다 JSON 파일 하나를 데이터 폴더의 `spools/`에 원자적으로 저장합니다. 전체 백업·복원에 함께 들어갑니다.
- **설치 패키지 검증:** 매 릴리스마다 세 OS에서 다음을 확인합니다.
  1. 스풀을 만들고 무게를 반영한 뒤 작업 하나만큼 빼기
  2. 실제 재시작 뒤 기록이 그대로인지
  3. 백업에서 복원한 뒤 기록이 그대로인지
  4. 스풀을 프린터 칸에 연결하면 “프린터에 장착”이 되고 연결이 재시작·복원 뒤에도 남는지
- **값의 근거:** 남은 양은 직접 적거나 저울로 잰 값과, 직접 고른 출력의 슬라이서 **예상치**로 계산합니다. 실제로 남은 양은 저울로 확인하세요.
- **아직 안 되는 것:** 프린터가 보고한 칸 정보로 스풀을 자동으로 찾아 연결하지는 않습니다. 사람이 칸마다 넣은 스풀을 고릅니다.

## 프린터 칸에 넣은 스풀

프린터 상태 화면에서 상태를 읽으면, 프린터가 보고한 AMS 칸과 외부 스풀마다 “재고 스풀” 선택이 나옵니다.

- **연결:** 실제로 넣은 스풀을 고르면 그 스풀에 프린터 시리얼과 칸이 기록되고 상태가 “프린터에 장착”이 됩니다. 한 칸에는 스풀 하나만 기록되므로, 이미 다른 스풀이 기록된 칸을 고르면 이전 스풀의 연결은 풀립니다. 프린터가 다르면 같은 번호의 칸도 다른 칸입니다.
- **해제:** “연결 안 함”을 고르거나 재고 화면의 “연결 해제”를 누릅니다. “프린터에 장착” 상태는 “개봉”으로 돌아갑니다.
- **재료 확인:** 기록한 스풀 재료와 프린터가 보고한 칸 재료가 다르면(예: PLA와 PETG) 경고만 보여 줍니다. 프린터 보고 값은 프린터에 입력된 값일 수 있어서, 어느 쪽도 고치지 않습니다.
- **보내기 확인:** 프린터로 보낼 때 필라멘트마다 칸을 고르면, 그 칸에 연결한 스풀과 기록상 남은 양을 보여 주고 슬라이서 예상 사용량보다 적으면 경고합니다. 보내기를 막지는 않습니다.
- **재고에서 빼기:** 이 화면에서 보낸 출력의 결과 카드는 보낸 칸에 연결된 스풀을 미리 골라 둡니다. 빼기 전에 바꿀 수 있습니다.
- **CSV:** 마지막 “프린터 칸” 열에 연결 위치가 들어갑니다.
- 이 기록은 사람이 고른 값이며, 프린터 화면의 칸 설정을 바꾸거나 프린터에 아무것도 보내지 않습니다.

## API

| 요청 | 내용 |
|---|---|
| `GET /api/spools` | 스풀 목록과 합계 |
| `GET /api/spools.csv` | CSV |
| `POST /api/spools` | 추가(201) |
| `PUT /api/spools/{id}` | 수정(`expected_revision` 필요) |
| `POST /api/spools/{id}/weigh` | `{expected_revision, gross_g}` |
| `POST /api/spools/{id}/use` | `{expected_revision, grams, job_id?}` |
| `POST /api/spools/{id}/slot` | `{expected_revision, serial, position}`(`ams-<0-7>-<0-7>` 또는 `external`, 둘 다 `null`이면 해제) |
| `DELETE /api/spools/{id}` | `{expected_revision}` |
