# 출력 실패 뒤 다음 조치

모델 화면의 **직접 확인한 결과를 남겨 주세요**에서 **출력 실패**를 고르면 원인을 여러 개 고를 수 있습니다.

- 첫 레이어가 안 붙음
- 모서리가 들뜨거나 휨
- 거미줄·실 날림
- 끼울 물건이 안 들어감(너무 꽉)
- 헐거움
- 약하거나 부러짐
- 글자 획이 뭉개짐
- 압출 부족·구멍 난 벽
- 출력 중간에 떨어지거나 엉킴

결과를 기록하면 **다음에 바꿔 볼 것**에 원인마다 일반적인 조치(출력판 청소, 브림, 온도, 필라멘트 건조 등)를 보여 줍니다.
측정한 진단이 아니라 흔한 원인에 대한 안내입니다.

## 모델 수정 제안

치수로 해결할 수 있는 원인에는 **모델 수정 검토** 버튼이 붙습니다. 현재 모델에 실제로 적용되는(범위 안의) 수정만 제안합니다.

| 원인 | 제안 |
|---|---|
| 너무 꽉 | 케이블 받침·원형 프레임·휴대폰 거치대: 여유 +0.2 mm · 이름 키링: 고리 구멍 +0.3 mm · 수납함: 가로·세로 +2 mm |
| 헐거움 | 여유 −0.1 mm(여유가 있는 템플릿, 0 미만으로는 줄이지 않음) |
| 약하거나 부러짐 | 벽 두께 +0.4 mm · 이름 키링: 받침 두께 +0.5 mm |
| 글자 획이 뭉개짐 | 이름 키링: 글자 크기 +2 mm |

버튼을 누르면 기존 **현재 제작안 수정**에 같은 문장(예: “여유 0.2mm 늘려줘”)이 들어가 변경 검토가 열립니다. 바로 바뀌지 않으며,
검토한 뒤 적용하고 다시 생성해야 합니다. 새 모델의 작업 기록에는 수정 내역이 남습니다.

원인은 출력 결과와 함께 작업 기록에 저장됩니다. 성공·미출력에는 원인을 저장하지 않으며, 예전 기록은 그대로 열립니다.
