# 용어·안내

“용어·안내” 화면은 처음 쓰는 사람이 무엇부터 하면 되는지, 화면에 나오는 말이 무슨 뜻인지 알 수 있게 돕습니다.

## 처음 쓰는 순서

다섯 단계와 각 단계를 여는 버튼이 있습니다.

1. **만들 것 고르기:** 시작점이나 문장으로 모델을 만들고, 가진 STL·3MF는 “가진 모델 점검”에서 불러옵니다.
2. **형상 점검 보기:** 얇은 벽과 돌출부를 미리 봅니다. 점검은 참고용이며 생성을 막지 않습니다.
3. **내 설정 넣기:** Bambu Studio에서 내보낸 프린터·필라멘트·공정 설정을 그대로 씁니다.
4. **슬라이스하고 보내기:** 이 PC의 Studio로 슬라이스하고, 원하면 LAN 프린터로 보냅니다.
5. **결과 기록하기:** 실제 출력 결과를 남기고, 쓴 필라멘트를 재고에서 뺍니다.

모델 화면 위쪽의 환영 안내는 “안내 닫기”를 누르면 그 브라우저에서만 다시 나오지 않습니다(브라우저 저장소를 쓸 수 없으면 다시 보입니다). 같은 내용은 언제든 “용어·안내” 메뉴에서 볼 수 있습니다.

## 용어 사전

- 재료·모델·형상·슬라이스·프린터·파일의 다섯 분류, 36개 용어가 있습니다.
- 한국어 이름, 영어 이름, 설명으로 찾을 수 있고 분류로 좁힐 수 있습니다.
- 각 용어에는 짧은 뜻, 이 앱에서 어떻게 쓰는지, 관련 용어, 그 말이 나오는 화면으로 가는 버튼이 있습니다.

주요 제목 아래의 “○○ 뜻” 버튼을 누르면 짧은 설명이 버튼 옆에 열립니다. Esc, 닫기 버튼, 바깥 클릭, 페이지를 크게 스크롤하면 닫히고, 키보드 초점은 버튼으로 돌아갑니다. “용어 사전에서 보기”는 사전의 해당 항목으로 이동합니다.

## 범위

- 설명은 이 프로젝트에서 쓰려고 쓴 쉬운 풀이입니다. 권장 온도·속도 같은 설정값은 주지 않습니다. 값은 프린터·필라멘트·모델마다 다르므로 내 설정 파일과 제조사 안내를 확인하세요.
- 용어 목록은 서버(`print_agent/glossary.py`)에서 검사한 뒤 첫 연결 응답에 담아 보냅니다. ID 중복, 없는 관련 용어, 알 수 없는 분류·화면이 있으면 서버가 시작 응답을 만들지 않습니다.
- 외부 사이트에서 아무것도 불러오지 않습니다.
