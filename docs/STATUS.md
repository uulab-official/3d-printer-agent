# Development status

Date: 2026-11-20 (Asia/Seoul).

Canonical repository: [uulab-official/3d-printer-agent](https://github.com/uulab-official/3d-printer-agent). The initial local prototype is the open-source v0.1 baseline. Version 0.30 is a local single-user application; observed desktop, browser and native qualification is recorded per source below. Hosted multi-user operation and physical printing have separate qualification requirements.

## Implemented

Version 0.30 gives every template a starting project. It adds a name keychain and Esc and Enter keycaps under two new purposes, 12 projects in all. Name-tag and keycap recipes state their outer size: exact for keycaps, a font-dependent upper bound for the keychain. Cards and placement comparisons use that size ([project discovery](PROJECT_DISCOVERY.md)). CI now caches the browser and apt downloads.

Version 0.29.1 adds a real-browser (Chromium, desktop and mobile) case for the print-send card. It uses real CAD and synthetic slice and printer responses, and changes no application behaviour. Published as [v0.29.1](https://github.com/uulab-official/3d-printer-agent/releases/tag/v0.29.1) on 2026-11-20 from `f9bacff`.

Version 0.29 refuses to send a file sliced for another known Bambu model. It also warns when fibre-filled (-CF/-GF) filament would run through a reported stainless-steel or brass nozzle, and when a sliced nozzle temperature is outside the chosen AMS slot's reported range. The model in the slice is compared with the product name the printer reports, and any name the app cannot place only warns. This is verified against the synthetic printer; real product-name formats are unverified ([LAN send](PRINT_SEND.md)). Published as [v0.29.0](https://github.com/uulab-official/3d-printer-agent/releases/tag/v0.29.0) on 2026-11-19 from `6164466`.

Version 0.28 adds slicer settings to the attempt history. Each successful slice keeps the key settings from its verified plan, and each attempt lists the settings that changed since the nearest earlier slice ([recovery](RECOVERY.md)). Published as [v0.28.0](https://github.com/uulab-official/3d-printer-agent/releases/tag/v0.28.0) on 2026-11-19 from `1c15c7b`.

Version 0.27 shows a print attempt history for a model made by editing an earlier one. Each earlier attempt lists its recorded outcome and reasons, the printer's own report and codes, and the reviewed changes between attempts. The history comes from stored edit links, is read-only and never infers a cause ([recovery](RECOVERY.md)). Published as [v0.27.0](https://github.com/uulab-official/3d-printer-agent/releases/tag/v0.27.0) on 2026-11-19 from `8374323`.

Version 0.26 links a printer's own finish/failure report to the job it was sent from (matching job name and a recorded start on the same printer), keeps the reported error and HMS codes apart from the person's outcome, and puts them first in the recovery steps with Bambu Lab's HMS search; verified against the synthetic printer only ([LAN send](PRINT_SEND.md)). Published as [v0.26.0](https://github.com/uulab-official/3d-printer-agent/releases/tag/v0.26.0) on 2026-11-19 from `21ac9e1`.

The app generates three parameterized CAD models; reviews user-supplied filament evidence and calibration changes; prepares Bambu CLI jobs; calculates user-entered delivered prices; and stores job artifacts and user reports. The optional LLM adapter only proposes supported typed model parameters. The Korean UI provides the same operations locally.

A local discovery catalog supplies six original starting projects across those three geometry templates. Purpose and optional placement-space filters compare the recipe's outer dimensions, including explicit horizontal rotation; they do not infer printer compatibility or physical fit. Browsing leaves current work intact, and a separate action prepares editable dimensions. Generation resolves the selected recipe against the server catalog and saves its identity, original parameters and customization record in the job, manifest and bundle. Source-free clients and historical jobs remain supported. See [PROJECT_DISCOVERY.md](PROJECT_DISCOVERY.md).

The filament workflow now imports related JSON documents, selects an editable target, resolves supported explicit single-parent inheritance, shows each value's source and assignment history, and exports an evidence report with the submitted setup. Missing parents can be added to the collection. Changes invalidate old results. See [FILAMENT_PRESETS.md](FILAMENT_PRESETS.md) for the supported subset and official-source references. This does not fill Studio defaults or certify a full native configuration.

Studio `.bbsflmt`, `.bbscfg` and preset `.zip` imports add filament documents directly, retain exact archive/member byte identity outside the original profile, and report excluded printer/process documents. The bounded parser does not extract files or execute Studio. Collection imports preserve pasted profiles and unfinished drafts, skip identical originals, reject conflicting names, and commit only after complete validation. Origin round-trips through saved workspaces and review reports. See [FILAMENT_ARCHIVES.md](FILAMENT_ARCHIVES.md) for source-derived format support and limits; a successful import does not resolve missing system parents or native variants.

Named filament workspaces preserve original documents, exact unfinished drafts, the selected target and all setup inputs across app restarts. A separate SQLite store uses revision checks for atomic updates and conflicts. Common-setting controls edit the selected draft while preserving inheritance and original evidence. Baseline comparison invalidates positive validation claims after effective settings change, including inherited parent changes. Reopening a saved workspace restores inputs and requires a fresh review. See [FILAMENT_WORKSPACES.md](FILAMENT_WORKSPACES.md).

An expandable evidence editor records the selected profile's seven applicability fields and four source fields independently of the current setup. Numeric and evidence changes share one atomic apply/cancel flow; raw profiles are wrapped only in the edited draft when evidence is applied. Original documents, unknown fields, validation claims and archive origins remain intact. Reports compare the target's own scope/source/validation separately from effective settings, and changed scope or validation makes a currently positive claim stale. Source-only corrections are recorded without implying new measurements or publisher authentication. This extends the existing workspace and review contracts without another endpoint or storage schema.

Native slicing preparation now assembles supplied machine/process/filament files with an explicit plate selection, validates native metadata and value representations, and rechecks staged configuration hashes and derived expectations before execution. An explicit UI/doctor probe reports the installed CLI's observed version/capabilities. Verified archive results include their SHA-256 and native version. See [BAMBU_STUDIO.md](BAMBU_STUDIO.md) for the supported subset and usage.

The original local validation is documented in [VERIFICATION.md](VERIFICATION.md). Current unit, package and browser results are recorded per commit in [GitHub Actions](https://github.com/uulab-official/3d-printer-agent/actions). A workflow definition alone is not evidence of a successful run.
