Bambu Studio CLI용 전체 machine·process·filament JSON을 선택하세요. 재료 검토 보고서나 상속이 남은 부분 프리셋은 전체 설정을 대신하지 않습니다. 파일의 상속 필드나 값을 지우거나 채우지 않습니다.

필라멘트는 표시된 순서로 포함합니다. 다시 선택하면 해당 종류의 선택을 교체합니다. 파일과 최종 요청은 각각 8 MiB까지 읽을 수 있습니다. 원본 파일은 수정하지 않습니다.

파일과 플레이트를 선택하세요.

01 · 설정 파일

필라멘트 프로필

Studio 내보내기(.bbsflmt·.bbscfg·.zip, 최대 4 MiB)에서 필라멘트 JSON을 읽거나 개별 JSON을 추가하세요. 빠진 부모 파일은 나중에 추가할 수 있습니다. 최대 64개이며, 원본 모음과 편집 문자열 모음은 파일 정보를 포함해 각각 2 MiB까지 지원합니다.

선택한 파일의 가져오기 정보

해시는 가져올 때 읽은 파일을 구분합니다. 발행처 인증이나 실물 출력 검증을 뜻하지 않습니다.

주요 설정 편집

JSON 파일을 가져오면 온도·유량·체적 속도를 항목별로 편집할 수 있습니다.

프로필의 적용 범위와 출처

선택한 파일의 원문에서 확인한 범위와 출처를 적어 주세요. ‘내 프린터와 재료’에 적은 사용 조건과 비교하며, 부모 파일의 근거를 자동으로 가져오지 않습니다.

빈칸으로 지운 항목은 적용할 때 해당 근거만 제거합니다. 다른 정보와 가져온 원본은 유지합니다.

입력한 값을 그대로 검토합니다. 누락된 온도·유량·체적 속도는 임의로 채우지 않습니다.

출처와 적용 범위는 어떻게 제공하나요?

파일을 가져오거나 입력한 JSON을 파일 모음에 추가한 뒤, 위의 ‘프로필의 적용 범위와 출처’에서 확인한 근거를 입력하세요. JSON으로 직접 제공할 때는 settings에 프로필을 담고 scope, source, validation 정보를 함께 넣을 수도 있습니다. 출처와 측정 기록은 입력된 정보이며 외부에서 검증된 것으로 간주하지 않습니다.

{
  "id": "프로필 식별자",
  "settings": {},
  "scope": {},
  "source": {},
  "validation": {}
}
